Лабораторна робота № 3. Розвідувальний аналіз і візуалізація даних

Мета: Опанувати відтворюваний процес розвідувального аналізу даних (Exploratory Data Analysis, EDA) на підготовлених у ЛР2 наборах: дослідити варіацію та коваріацію змінних, описати розподіли статистиками та графіками, виявити потенційні аномалії, сформулювати й попередньо перевірити розвідувальні гіпотези та підготувати інтерпретовані візуалізації.

Індивідуальне завдання на лабораторну роботу

Дані — демографічний набір щодо України за 1950–2026 рр. (Worldometer, отриманий через html/json mining у ЛР2, файл data/raw/median_year.json).

Виконані пункти індивідуального завдання:

  1. сформульовано три аналітичні запитання (розділ «Аналітичні запитання»);
  2. для двох кількісних змінних (total, fertilityRate) побудовано описи розподілу (числові статистики та графіки);
  3. знайдено потенційні аномалії для кількісних ознак (правило 1.5·IQR + змістовний аналіз різких стрибків);
  4. досліджено зв’язки між змінними (fertilityRate vs medianAge; fertilityRate vs total) та порівняно розподіли між декадами;
  5. сформульовано дві робочі гіпотези з графічними/числовими свідченнями й обмеженнями;
  6. створено підсумкову аналітичну таблицю та збережено п’ять графіків у figures/;
  7. написано висновок.

Аналітичні запитання

  1. Варіація чисельності. Як змінювалась і наскільки сильно варіювала чисельність населення України (total) протягом 1950–2026 рр.?
  2. Варіація та аномалії народжуваності. Який рівень народжуваності (fertilityRate) є типовим, чи є нетипові (аномальні) значення та які?
  3. Коваріація та групи. Чи пов’язане зниження народжуваності зі старінням населення (medianAge), з динамікою чисельності населення (total) і чи відрізняється народжуваність між десятиліттями?

Крок 2. Завантаження підготовлених даних

У ЛР2 дані отримані з Worldometer і збережені у data/raw/median_year.json.

demo_path <- "data/raw/median_year.json"

if (!file.exists(demo_path)) {
  stop("Не знайдено файл")
}

demo_all <- fromJSON(demo_path)

demo <- demo_all |>
  select(year, total, medianAge, fertilityRate, urban, migrantNet, yearlyGrowthRate) |>
  mutate(total_mln = round(total / 1000000, 2))

demo

year - рік.

total — чисельність населення.

fertilityRate — коефіцієнт народжуваності.

medianAge — медіанний вік населення.

migrantNet — міграція (нетто).

urban — частка населення, що проживає в міських районах.

yearlyGrowthRate - відносний приріст населення (yearlyGrowth / prevTotal).

Перевіримо контракт даних: унікальність ключа year, коректність значень.

stopifnot(
  !anyDuplicated(demo$year),
  all(demo$total >= 0, na.rm = TRUE),
  all(demo$total_mln >= 0, na.rm = TRUE),
  all(demo$fertilityRate > 0, na.rm = TRUE),
  all(demo$medianAge > 0, na.rm = TRUE)
)

Вибірка нерівномірна - до 2020 інтервали 5-річні, а 2026 стоїть за рік після 2025.

Крок 4. Варіація: чисельність населення

Запитання: яка чисельність населення типова для цього набору і наскільки сильно вона змінюється?

demo |>
  summarise(
    n = n(),
    mean_total = mean(total_mln),
    median_total = median(total_mln),
    sd_total = sd(total_mln),
    iqr_total = IQR(total_mln),
    q1 = quantile(total_mln, 0.25),
    q3 = quantile(total_mln, 0.75),
    min_total = min(total_mln),
    max_total = max(total_mln)

Крок 6. Потенційні аномалії

Використаємо boxplot та правило \(1.5\,IQR\).

bounds <- demo |>
  summarise(
    total_low  = quantile(total_mln, 0.25) - 1.5 * IQR(total_mln),
    total_high = quantile(total_mln, 0.75) + 1.5 * IQR(total_mln),
    fert_low   = quantile(fertilityRate, 0.25) - 1.5 * IQR(fertilityRate),
    fert_high  = quantile(fertilityRate, 0.75) + 1.5 * IQR(fertilityRate)
  )

outlier_candidates <- demo |>
  filter(
    total_mln < bounds$total_low | total_mln > bounds$total_high |
    fertilityRate < bounds$fert_low | fertilityRate > bounds$fert_high
  )

nrow(outlier_candidates)

  ) +

p_box_fert

Розрахуємо зміну чисельності між сусідніми спостереженнями.

demo_change <- demo |>
  mutate(
    total_change = total_mln - lag(total_mln),
    interval_years = year - lag(year)
  ) |>
  select(year, total_mln, interval_years, total_change) |>
  filter(!is.na(total_change)) |>
  arrange(desc(abs(total_change)))

demo_change

Інтерпретація аномалій: (1) 2025 — найбільше одноразове скорочення (−5.70 млн за період 2020–2025); (2) 2026 — єдиний з часів спаду рік приросту (+0.56 млн), який суперечить усій попередній динаміці. Не видаляємо ці рядки: правдоподібне пояснення — наслідки війни та можливі зміни методики обліку населення у джерелі (наприклад, урахування біженців, що перебувають за кордоном). Рядки позначаємо як «аномальні по суті, але реальні» і враховуємо це при інтерпретації трендів після 2020.

Крок 10. Перевірка розвідувальних гіпотез

Дві робочі гіпотези, сформульовані за результатами EDA:

H1: зниження народжуваності пов’язане зі старінням населення (обернений зв’язок fertilityRate – medianAge).

c(r_fert_age = r_fert_age)
r_fert_age 
-0.9343485

Свідчення: точкова діаграма з лінією регресії, \(r \approx -0.93\) (Крок 7).

H2: після 1991 р. народжуваність системно нижча, ніж у радянський період.

era_summary <- demo |>
  mutate(era = if_else(year < 1991, "До 1991", "Після 1991")) |>
  group_by(era) |>
  summarise(
    n = n(),
    mean_fert = round(mean(fertilityRate), 3),
    median_fert = round(median(fertilityRate), 3),
    .groups = "drop"
  )

era_summary

Свідчення: середнє до 1991 — 2.10, після — 1.22 (медіани 2.05 і 1.22); окремий boxplot (нижче) та boxplot за декадами (Крок 9) показують, що всі точки 1990-х і пізніших періодів лежать нижче фактично всіх точок 1950–1980-х. Обмеження: відмінність по групах може бути наслідком і структури віку, і соціально-економічних трансформацій.

Висновок

У ході виконання лабораторної роботи опановано повний цикл розвідувального аналізу даних (EDA):

  1. Варіація та розподіли: досліджено дві кількісні змінні – total (середнє 45.82 млн, sd 4.69, розкид від 37.3 до 52.05 млн) та fertilityRate (середнє 1.69, sd 0.49, від 0.997 до 2.447). Показано, що гістограма маскує часову структуру, тому для часових рядів основний аналітичний графік – лінійна діаграма.
  2. Аномалії: за правилом \(1.5IQR\) кандидатів не знайдено, але змістовний аналіз різких стрибків виявив підозрілі точки (2025 — найбільше одноразове скорочення населення −5.70 млн, 2026 — єдиний від часів спаду рік приросту +0.56 млн). Рядки не видалено, а позначено як аномальні по суті та пов’язані з війною і можливою зміною методики обліку у джерелі.
  3. Коваріація та групи: встановлено сильний обернений зв’язок народжуваності з медіанним віком (\(r \approx -0.93\)), майже нульову лінійну асоціацію народжуваності з чисельністю населення (\(r \approx 0\), пояснено зсувом фаз двох часових тенденцій), а також системне зниження медіан народжуваності від 2.38 (1950-ті) до ~1.0 (2020-ті).
  4. Гіпотези та обмеження: сформульовано дві розвідувальні гіпотези (зв’язок народжуваність–старіння; зниження народжуваності після 1991), для кожної вказано свідчення, обмеження (малий n, часові конфаундери, агреговані оцінки джерела) і наступний крок перевірки.
